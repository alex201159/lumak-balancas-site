# Lumak Balanças

Site institucional da Lumak Balanças, com páginas para empresa, balanças, vendas, assistência técnica, área técnica, localização e contato.

## Como abrir localmente

Abra o arquivo `index.html` no navegador ou rode um servidor estático:

```bash
python3 -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000/index.html
```
